# 歴史年号暗記クイズ (日本史＆世界史)

日本史（281件）と世界史（150件）の重要年号を暗記・演習できるReactアプリケーションです。

## 主な機能

- **通常クイズ**:
  - **出来事➔年号** (直接入力): 画面テンキーおよび物理キーボード対応の4桁西暦入力
  - **年号➔出来事** (4択クイズ): 年号から対応する出来事を選択
  - **暗記カード** (フラッシュカード): カードをタップして反転、「覚えた」「覚えてない」で予習・反復学習
- **並べ替え・同時期**:
  - **通常の並べ替え**: 4つの出来事を古い順にドラッグ/タップで並べ替え
  - **同時期のできごとクイズ**: 日本史と世界史のほぼ同時期に起こった出来事を対比して出題
- **苦手克服システム**:
  - 間違えた問題を自動追跡し、3回連続正解で「克服」バッジを獲得
  - 苦手克服モードで優先出題
- **歴史年表（タイムライン）**:
  - 日本史と世界史を西暦年ごとに縦に揃えて横スクロール比較
  - キーワード検索、クイックプリセット（信長、明治、宗教改革、世界大戦、条約、年代範囲、苦手）
  - 検索結果に合致した問題だけを抽出してクイズを開始できる「絞り込み特訓」機能
- **Study Tracker 連携**:
  - 暗号化（PBKDF2 + AES-GCM）による学習時間とスタッツのクラウド同期

## 開発環境

- **フレームワーク**: React 19 + TypeScript + Vite
- **スタイリング**: Tailwind CSS
- **ポート**: 3000 (`npm run dev`)
